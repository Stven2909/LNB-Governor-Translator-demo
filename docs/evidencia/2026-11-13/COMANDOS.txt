 BLOQUE 5 - RECORRIDO COMPLETO (VENTANA C)
================================================================================

# Health del agente (esperado: {"status":"UP"})
curl.exe -s http://localhost:8080/actuator/health/readiness

# Caso 1: boleto ganador (esperado: result=FOUND, traceId=demo-001, SEED)
$body = '{"ticket":{"lotteryCode":"LNB","drawNumber":"2026-10-15","ticketNumber":"0012345678"}}'
Invoke-RestMethod -Method Post -Uri http://localhost:8080/api/v1/agent/ticket-query -ContentType 'application/json' -Headers @{ 'X-Correlation-Id'='demo-001' } -Body $body | ConvertTo-Json -Depth 6

# Controles: 0011111111 -> NOT_AWARDED / 9999999999 -> NOT_FOUND
foreach ($t in '0011111111','9999999999') {
  $payload = @{ ticket = @{ lotteryCode='LNB'; drawNumber='2026-10-15'; ticketNumber=$t } } | ConvertTo-Json -Compress
  Write-Host "--- $t"
  Invoke-RestMethod -Method Post -Uri http://localhost:8080/api/v1/agent/ticket-query -ContentType 'application/json' -Headers @{ 'X-Correlation-Id'="demo-$t" } -Body $payload | ConvertTo-Json -Depth 6
}

# E2E con traza guardada (esperado: === E2E OK ===)
.\scripts\verify-agent-e2e.ps1 -WsUrl http://localhost:8085 -AgentUrl http://localhost:8080 -OutFile docs\evidencia\2026-11-13\e2e-2026-11-13.txt

================================================================================
 CHULETA: SI FALLA
================================================================================

Puerto ocupado            -> Get-NetTCPConnection -LocalPort 8080,8085 -State Listen
400 Bad Request           -> se uso curl.exe con body; usar Invoke-RestMethod
502 o 504 en el agente    -> el WS no esta arriba (Ventana A)
200 en fail-closed        -> el WS sigue vivo, o el agente esta en modo FIXTURE
demo-live no arranca      -> el agente sigue ocupando el 8080 (Ctrl+C en Ventana B)
"python"/"mvn" no existe  -> usar .\mvnw -DskipTests package
